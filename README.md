# VORTIQRA – Outpost Commander

**Train • Learn • Explore**

A Junior Astronaut Mission Trainer for ages 8–16, built for the **NASA Space Apps Challenge 2026** — challenge: *Build a Junior Astronaut Mission Trainer*.

**Live app:** https://parvindarjambra.github.io/vortiqra-site/

## What it is

Cadets take command of a lunar or Mars outpost and learn real space science by running it:

- **Pick a destination** — Moon (Artemis Lunar Outpost) or Mars (Mars Frontier Base). The briefing, hazards and mission events change with the choice.
- **Command Center** — 4 interactive panels: Life Support & ECLSS, Solar & Nuclear Power Grid, Hydroponics Food Lab, Deep Space Communications. Each stabilized system earns XP.
- **5 live resources** — Oxygen, Water, Food, Electricity and Crew Safety update in real time as cadets move sliders, answer scenario decisions (A/B/C) and survive random mission events.
- **Red Alert** — 60-second emergency crisis simulator with real NASA protocols.
- **Space Academy** — 6 flip flashcards plus a 5-question certification quiz. Scoring 80%+ earns the Certified Outpost Commander badge.
- **Final Mission Report + certificate** — a mission debrief (SUCCESS if all resources stay above 20%) and a printable certificate with the cadet's name, XP and rank.

Progress (name, rank, XP, badges) saves on the player's own device. No sign-up, no server, no cost.

## Run it

The whole app is a single self-contained file — no build step, no dependencies:

- Open `index.html` in any modern browser, or
- Visit the live link above.
